Client Integration Guide

Connect your AI coding assistants through this Gateway on port 20129:

  1. Open Cursor Settings > Models > OpenAI API Key.
  2. Enable Override OpenAI Base URL and enter:
    {{ .CurrentBaseURL }}
  3. Paste your API Key:
    {{ .UserKey }}
  4. Select or type whitelisted model ID: {{ .UserModel }}
API Provider: OpenAI Compatible
Base URL: {{ .CurrentBaseURL }}
API Key: {{ .UserKey }}
Model ID: {{ .UserModel }}
1. Add to ~/.hermes/.env: 
GATEWAY_API_KEY={{ .UserKey }}
2. Add to ~/.hermes/config.yaml under custom_providers: 
custom_providers:
  - name: AI Manager
    base_url: {{ .CurrentBaseURL }}
    key_env: GATEWAY_API_KEY
    model: {{ .UserModel }}
    api_mode: chat_completions
Test Curl Command: 
curl -X POST {{ .CurrentBaseURL }}/chat/completions \
  -H "Authorization: Bearer {{ .UserKey }}" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "{{ .UserModel }}",
    "messages": [{"role": "user", "content": "Hello!"}],
    "stream": true
  }'
