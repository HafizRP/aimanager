Client Integration Guide

Connect your AI coding assistants through this Gateway on port 20129:

  1. Open Cursor Settings > Models > OpenAI API Key.
  2. Enable Override OpenAI Base URL and enter:
    http://100.108.204.127:20129/v1
  3. Paste your user API Key (sk-gw-...) created from the Users/Keys menu.
  4. Add your whitelisted model ID (e.g. ag/gemini-3.8-flash-high).
API Provider: OpenAI Compatible
Base URL: http://100.108.204.127:20129/v1
API Key: sk-gw-your-api-key
Model ID: ag/gemini-3.8-flash-high
In ~/.hermes/config.yaml under custom_providers: 
custom_providers:
  - name: 9router Gateway
    base_url: http://localhost:20129/v1
    key_env: GATEWAY_API_KEY
    model: ag/gemini-3.8-flash-high
    api_mode: chat_completions
Test Curl Command: 
curl -X POST http://100.108.204.127:20129/v1/chat/completions \
  -H "Authorization: Bearer sk-gw-..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ag/gemini-3.8-flash-high",
    "messages": [{"role": "user", "content": "Hello!"}],
    "stream": true
  }'
