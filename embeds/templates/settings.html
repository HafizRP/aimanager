Client Integration Guide

Connect your AI coding assistants to this Gateway wrapper on port 20129:

  1. Open Cursor Settings > Models > OpenAI API Key.
  2. Enable Override OpenAI Base URL and enter:
    http://127.0.0.1:20129/v1
  3. Or for remote devices via Tailscale:
    http://100.108.204.127:20129/v1
  4. Paste your user API Key (e.g. sk-gw-...) and add desired model (e.g. ag/gemini-3.8-flash-high).
API Provider: OpenAI Compatible
Base URL: http://127.0.0.1:20129/v1
API Key: sk-gw-your-api-key
Model ID: ag/gemini-3.8-flash-low or any whitelisted model

In ~/.hermes/config.yaml under custom_providers:

custom_providers:
  - name: 9router Gateway
    base_url: http://localhost:20129/v1
    key_env: GATEWAY_API_KEY
    model: ag/gemini-3.8-flash-high
    api_mode: chat_completions
Test Curl Command: 
curl -X POST http://127.0.0.1:20129/v1/chat/completions \
  -H "Authorization: Bearer sk-gw-..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "ag/gemini-3.8-flash-low",
    "messages": [{"role": "user", "content": "Hello!"}]
  }'
