Claude Code CLI Setup
Run Anthropic Claude Code backed by your AI Manager high-speed quota

Export these environment variables in your terminal before launching claude:

export ANTHROPIC_BASE_URL="{{ .BaseURL }}"
export ANTHROPIC_API_KEY="{{ .UserKey }}"
export CLAUDE_DEFAULT_MODEL="main"
claude
Tip: Use "main" as model to automatically failover from Claude Sonnet to Gemini 3.8 Flash if rate limits hit!
